## Opening and running the notebooks

1. Open any `.ipynb` file in JupyterLab, Jupyter Notebook, or Google Colab. GitHub can also preview notebook contents.
2. Use Python 3 with the packages listed in `requirements.txt`.
3. Run the notebook cells in order to recreate the calculations and figures.

To install the primary dependencies locally:

```bash
python -m pip install -r requirements.txt
```
